# Sebastian — Roblox UI Portfolio

A static HTML/CSS/JS portfolio inspired by the structure of the reference portfolio you provided, but designed from scratch for Roblox UI/UX work.

## Files

- `index.html` — page structure and content
- `style.css` — visual design and responsive layout
- `script.js` — portfolio cards, filters, modal viewer, navigation, toast messages
- `assets/work/` — temporary demo SVG thumbnails

## Before publishing

1. Replace the demo SVG files in `assets/work/` with screenshots of your actual work.
2. Update the project information at the top of `script.js`.
3. Replace the placeholder Discord and email links in `index.html`.
4. Change any wording you want in `index.html`.

## Run locally

Open `index.html` in your browser. No Node.js or build step is required.

## GitHub Pages

This is a static site, so it can be published directly through GitHub Pages. Create a repository, upload these files, then enable Pages from the repository's Settings > Pages.
